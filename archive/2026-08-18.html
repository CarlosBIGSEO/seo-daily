El Content API for Shopping se apaga hoy: quien no haya migrado pierde sus fichas de producto

Google cierra definitivamente hoy, 18 de agosto, el Content API for Shopping: cualquier integración que aún suba datos de producto por esa vía deja de funcionar y las fichas afectadas pueden desaparecer de Merchant Center. La migración a Merchant API (v1) llevaba meses anunciándose —con un primer plazo el 28 de febrero para los usuarios de v1beta—, pero las subidas manuales, los feeds programados y Google Sheets no se ven afectados.

Por qué te importa

Cómo saber si te afecta hoy mismo

  • Si tu feed se sube vía API (no manual ni por Sheets), comprueba ya el estado de tu migración a Merchant API v1.
  • Una caída repentina de productos activos en Merchant Center hoy es la primera señal de alarma.
  • Los usuarios de Merchant API v1beta debían migrar a v1 antes del 28 de febrero; hoy ya no queda margen para nadie.
